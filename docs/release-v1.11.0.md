# v1.11.0：宏微观综合训练与知识导图

本版把宏微观题目组织、综合训练和知识点联系接入同一套学习流程。

- 原200道专项按实际任务分层，条件与编号小问分开呈现，保留原题干回查。
- 新增40道编者综合题，每科每专题2题，逐问参考作答和评分；新增3套100分限时卷，交卷前隐藏答案和路径提示。
- 新增20专题知识导图、知识拓扑和逐问路径：263节点、284条学科内联系、7条跨科联系，覆盖139张知识卡和240题708个编号分问。
- 支持概念/别名搜索、关系词遮盖复述、知识卡返回、图形缩放、跟读及独立作答；认识概念、解释联系、独立解题分别自评并随备份及服务器保存。
- 双向反馈曲线与标签分开排布；知识目录不完整时停止初始化，保留已有学习记录。

既有三科300题、323张知识卡和50天计划继续保留；综合题另行统计。新增内容分别标注既有资料概括、编者推导和编者类比，不标为教材逐字原文或官方评分答案。

## 本地验收依据

新增知识体系全部节点、关系、分问和跨科联系均完成独立逐条审读，修复后回读并绑定最终内容指纹。26个补充节点当前没有直接检验分问，界面明确提示，不为覆盖数硬挂题目。

- 构建成功，37,605项内容及资源检查通过。
- 565项自动测试通过，含旧备份兼容、三层合并、综合题评分与限时卷、缺目录后保留数据库等场景。
- 桌面和390像素手机回归覆盖252项；首轮250项通过，2项旧导航数量检查更新为完整8入口核对后补测通过。
- 新知识体系最终渲染底稿2308个数学表达式严格解析通过。

版本标签对应的远端构建、原生amd64/arm64镜像及部署包以该标签的发布工作流结果为准；上述本地验收不代表既有公网实例已经升级。
