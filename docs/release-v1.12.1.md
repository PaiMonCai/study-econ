# v1.12.1：简洁阅读与自主刷题

首页直接进入“刷题训练”，由学习者选择科目、专题、题量与顺序；“今日安排”及计划日期设置从界面移除。旧 `#today` 地址回到题库，历史计划记录与备份兼容，未完成阅读或练习可从首页继续。

## 阅读与翻题

- 阅读页底部常驻上一题、下一题，正文留出底部空间；长答案展开和专注阅读时仍可翻题。到本组末题时沿用结束本组流程。
- 单题阅读接入本专题连续阅读；从现有多题练习切换跟读时保留该队列。旧单题跟读恢复时保留逐行位置，并扩展到本专题后续题。
- 字号、字体收进阅读设置，选择后收起并恢复焦点；专注阅读保留直接入口。跟读、展开与翻题不自动生成作答或掌握记录。
- 旧计划日期、自查、记录、草稿、收藏和照片随原学习库与JSON备份保留；自由练习不补记历史计划日。数据库与访问保护配置沿用既有版本。

## 答案来源与教材核对边界

规范作答包括AI依据题干编写的推导、补充条件和步骤重排。题源说明明确其编者参考作答身份，不作为教材逐字原解或官方评分细则。

本轮重点核对MI001、MI003、MA001，27份内容JSON与改动前逐字节一致，全部300题作答正文保留。不是对其余197道宏微观题重新逐页审计。

MI001要求以旧效用为基准补偿，故采用希克斯分解。平新乔《微观经济学十八讲》第二讲印刷第20–21页（本地扫描PDF物理第28–29页）讲支出最小化与希克斯需求；第三讲印刷第29–30页（物理第37–38页）采用希克斯补偿法，印刷第31–32页（物理第39–40页）推导斯拉茨基微分公式。有限变动中固定原消费束购买力的斯勒茨基补偿与固定旧效用不同，不能据此直接判定现行步骤错误。

MA001的稳态、维持投资及黄金律步骤与核读的曼昆第10版印刷第175、185–186页、多恩布什第13版印刷第52、57页的相应原理相符；具体数值按本题离散积累式独立复算。MI003的CV、EV分别固定旧、新效用，不混同两种效应分解。本次14项针对性预算、效用、分解加总与精确分数计算通过。这些记录不构成人工专家认证。
