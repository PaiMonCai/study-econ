# v1.13.1：恢复双页阅读

刷题训练的“看规范作答”入口恢复桌面双页：左侧题目和完整图形，右侧解题思路、全部步骤、知识点、条件与易错及整题主线。普通阅读与专注阅读都保留双页。小于1000像素的窄屏按题目、图形、解答上下排列。

完整内容仍直接显示，保留30篇整篇专题、字号和字体、底部上一题/下一题、方向键翻题及同一浏览器标签页的阅读位置恢复。题源和整理记录继续在独立完整页面查阅。独立作答、限时卷和闭卷检测仍先作答后核对。

## 修正原因

v1.13.0把“取消展开、改善阅读”扩大为单栏布局，导致刷题首页主要的规范作答入口不再左右分栏。本版恢复双页，题目和图形可留在左侧对照右侧答案。独立作答页继续使用既有双页。

全部27份内容JSON、300题题干与解答、来源及图形数据保持原样；学习记录、照片、自评、草稿、收藏、备份与服务器保存机制沿用既有版本。本次没有新增教材内容审校结论。

## 验证依据

- 本地36项相关界面检查首轮35项通过；另1项旧测试固定滚动1400像素，而双页后的该题只能滚动1389像素。测试改为根据实际页面高度选择可达位置，仍精确核对保存、翻回、刷新及来源返回坐标；桌面和手机2项复测均通过。
- 双页检查验证题目和图形位于解答左侧、两页顶部对齐；普通与专注模式均通过。三科代表题在1600、1280、1000、390、320像素下共15份大字号预览，未见页面撑宽或脚本错误。
- 本地584项程序测试与38,479项内容检查通过。原始失败、复测与截图继续保留，未跳过检查或增加重试。

本标签工作流重新执行全站桌面/手机界面回归、构建、程序测试与内容检查，并在原生amd64、arm64环境检查容器根路径、`/802`子目录、重启保存和Compose数据库重建。远端最终结果以对应提交的工作流为准；浏览器视口和容器验证不等于实体手机或已有公网服务器验收。

升级保留自己的`.env`、原Compose项目名和数据卷，使用`ghcr.io/paimoncai/study-econ:v1.13.1`。发布标签不会自动升级已有服务器。
