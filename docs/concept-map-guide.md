# 人大802知识导图与拓扑使用说明

本地练习室的“知识导图与拓扑”把宏观、微观各10个专题组织成同一份可回查的知识底稿。知识点、关系与题目分问分别维护，三种视图共用它们。

## 三种视图

| 视图 | 看什么 | 怎样学习 |
|---|---|---|
| 知识导图 | 专题问题、知识分支、单一概念及其主归属 | 先说出这一章解决的问题，再解释每个分支怎样展开 |
| 知识拓扑 | 以所选节点为中心的前置、推导、对照、条件变化、机制和类比 | 说清一条联系的命题、成立条件和理由，点击邻接点继续探索 |
| 解题路径 | 具体题目、编号小问、实际调用节点与关系 | 先独立做题，再检查为什么调用这些节点；条件改变时重新判断路径 |

拓扑图的实线箭头表示从起点到去向的有方向联系；虚线无箭头表示对照或方法类比。图中关系词用于快速定位，完整关系命题、条件、理由和来源摘录保留在图后的文字列表。不能仅凭同章出现、符号相似或同题共现认定推导。

## 一个知识点怎样读

选中节点后，右栏依次给出定义与对象、触发条件、适用条件、公式与机制、推导理由、边界与易错。桌面两栏可分别滚动；手机改为上下阅读，点击导图节点后进入详情。关系图默认适应栏宽，需要细看时点击“放大关系图”，在图内横向移动。

同一概念有唯一主归属，跨专题使用时复用节点。跨科联系仅在明确对象、条件和差异之后建立；方法类比不能代替经济含义和模型闭合条件。某些补充知识点当前没有直接对应的小问，会明确显示这一点。

## 怎样练习复述

在知识拓扑中点击“遮住关系词，练复述”。先看两个知识点，说明怎样联系、在什么条件下成立，再点击“核对这条联系”。只记箭头或名称不算完成；至少应能用一句话解释关系，再把条件改变后的情况说出来。

三层自评分开记录：

1. 认识概念：能否准确说出对象、定义与适用条件。
2. 解释联系：能否说明推导、机制、对照或类比为什么成立。
3. 独立解题：能否在不预看路径时独立选法并完成对应小问。

每层可选“不会、不熟、能复现”。打开节点、展开说明、查看图形或阅读路径不会自动计为掌握。自评随现有JSON备份保存；服务器模式也随学习库保存，换浏览器登录可恢复。旧版备份没有三层自评时，原有作答、草稿、收藏与背诵记录仍可导入。

## 怎样接回题目

节点详情中的“把它用回题目”列出实际使用该点的题目及具体小问；解题路径也可从本专题题目下拉框选择。路径页保留完整题干入口、本问任务、调用理由、节点与关系，并可进入跟读或独立作答。

规范作答区在核对答案后提供本题路径入口。未交卷的限时卷不在作答页展示路径提示。路径是编者对当前参数、制度和设问的分析；换题之后，仍须根据新条件重新决定模型与分支。

## 来源与打印

“既有资料概括”“编者推导”“编者类比”分别标识。依据摘录来自已交付知识卡、专题串联、专项审校或编者综合题，提供实际回查入口；这些出处不自动成为教材逐字原文或官方评分答案。

网页可打印当前专题视图和节点内容。两科离线总稿由同一底稿生成，包含分支图、关系图、逐点教学、关系条件与逐问应用；其中Mermaid代码块需要支持Mermaid的Markdown阅读器渲染。配套“知识导图图示”目录另提供40幅SVG/PNG和“图示索引.html”，浏览器离线打开即可查看；分支图采用分栏排布，专题全图打印默认A3横向，SVG也可按需要缩放。专题全图仅画主归属节点，跨专题关系在正文逐条列出，并可在练习室逐点追踪。完整交互以本地练习室为准。
