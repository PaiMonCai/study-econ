# v1.12.0：宏微观15天强化、作答速查与闭卷检测

首页默认采用宏微观15天强化安排，作答速查和闭卷检测接入今日任务、专题串联与知识节点，便于在同一学习流程中选法、作答、订正和复测。

- 面向学过一轮、每天有4至6小时的学习者，前10天安排40道代表题完整作答、160道条件与选法筛查；第11至13天练综合应用，第14至15天分别用P02、P03进行120分钟限时训练。默认开始日期为2026年11月4日，可单独调整。
- 宏微观各10专题、每专题两页，共40页作答速查，含20组典型起笔式、80条题干信号与条件分支，附易混对照、闭卷重建和整题回练。
- 新增66道编者短检测：20专题各有选法和条件变式题，共40题；另26题直接检验原知识图中暂无专项或综合题分问的补充节点。每题保留知识节点及依据片段。
- 检测草稿、参考展开、订正标记和最近20轮自评独立保存，并支持浏览器、服务器和JSON备份。检测不增加原题完成数或知识掌握自评。
- 随站提供40页PDF、含字体的离线HTML、速查Markdown、仅题目稿和参考与自查稿。网页打印检测时只显示题干与作答区。

原50天三科计划、300题、323张知识卡、20专题知识图及40道综合题继续保留。新增内容为编者压缩、推导和训练设计，不是教材逐字引文、官方原题或评分细则；满分是训练目标，完成计划或勾选自查不自动视为掌握。
