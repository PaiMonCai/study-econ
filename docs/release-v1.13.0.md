# v1.13.0：完整正文与纯阅读体验

题目阅读现在打开即可连续读完：题干、解题思路、全部步骤、条件与易错、背诵主线和完整配图直接显示。30篇专题整篇展示，目录用于定位段落。逐行展开、答案遮盖、知识点折叠及阅读图形面板的折叠已移除。

## 阅读与翻题

- 阅读正文采用单栏；字号、宋体或黑体、专注阅读直接可选。底部常驻上一题、下一题与当前题序，正文保留底部空间。
- 正文可用左右方向键翻题；选中文字、操作表单或查看图形时不触发翻页。配图直接显示完整阶段，放大后仍保留完整图形。
- 同一浏览器标签页按题号、字号、字体和屏幕宽度类别保存滚动位置；翻回、刷新、回查知识卡或从题源页返回时恢复。它不是跨设备同步的逐段阅读进度；题组、当前题和阅读偏好仍由原学习库保存。
- 旧单题、隐藏答案和逐行进度会话恢复后显示完整正文；阅读和翻题不自动产生作答、自评或掌握记录。
- 题源、审校记录、整理前题干、保留原解答和图形依据集中到独立的“题源与整理记录”页面，均完整显示。正文继续明确其AI编者参考作答身份。

独立练习仍先自行作答，核对时一次显示完整步骤、知识点与主线。限时卷和闭卷检测保留交卷前隐藏参考答案的流程。照片、历史文字作答、收藏、自评、备份、服务器同步及访问保护沿用既有机制。

## 内容与排版边界

全部27份内容JSON保持原样，包含300题题干与解答、审校作答、30篇专题、40道综合题、知识卡和图形数据。本轮没有新增教材内容审校结论。

独立公式后紧跟标点时的识别已修正，消除微观05中残留的美元符号；仅5处生成HTML字段发生排版变化，非HTML题库数据不变。窄屏知识卡长标题允许换行，解决独立核对页和综合题页面撑宽的问题。
