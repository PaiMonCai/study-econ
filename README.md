# 人大802练习室 · 独立部署版

三科各100道独立训练题，30个专题，50天每日每科10题。配套323张知识卡。支持拍照作答、逐步核对、知识点复盘、公式与背诵、自评、错题和JSON备份迁移。

计算题与论述题需要自行对照解答评估，网站不自动判分。学习进度、回忆草稿和作答照片保存在服务器SQLite数据库。同一访问口令下的设备共用一份学习库，换浏览器后登录即可继续；不回写原Excel。

## 本机使用

部署方式和完整命令见 [DEPLOY.md](DEPLOY.md)。支持Docker Compose、直接Node服务和Nginx反向代理；无需Sites账号、ChatGPT登录或OpenAI密钥。

先按DEPLOY.md配置访问密码或URL token，再运行服务；公网监听未配置口令时会拒绝启动。本机预览可设置`HOST=127.0.0.1`。预先构建的成品不需要安装npm依赖。全部公式、字体和资料已放在本地，无需连接外部公式服务。

## 更新题库

`content/` 保存已交付题库和计划的快照；原编制目录及原手册不会被网站修改。编辑快照后运行 `npm ci`、`npm run build`、`npm run check`。构建会预先转换全部公式，遇到解析错误时停止；`build-manifest.json`记录输入哈希和数量。运行`npm test`测试服务，`npm run package`生成可搬运部署包。

`dist/materials/` 是随站点提供的基础册、训练册和计划。原真题PDF不随站点上传；每题列出其原文件名、年份题号与PDF物理页。若本地原资料存在，重建时会同步这些配套手册。

## 学习数据

在“设置与备份”导出包含照片的服务器JSON备份；需要迁往另一台服务器时导入。导入合并练习记录和收藏，同一记录按最近修改时间保留，不重复计数。同题草稿以导入文件为准。换浏览器、设备或域名时，只要仍连接原服务器数据库，登录后即可继续。旧版浏览器数据可在设置页确认后迁入服务器，原数据仍保留。

内置访问密码、URL token及登录凭证；题库、解答、PDF与数据接口都受保护。这是单人共享学习库，不区分多个账号。源码、网页和部署包不需要Sites配置。`node_modules/`、本机测试截图、运行日志与自定义`.env`不进入发布包。

## 阅读与作答

阅读页可选小、标准、大字号及宋体/黑体；专注模式收起导航与题号侧栏。刷题页改为纸上作答后拍照或选择图片，每题最多3张，支持放大、删除、切题与刷新恢复；历史文字草稿保留在折叠区。图片上传到服务器数据库，仍由你自行核对，不自动识别或批改。

点“作答结束，核对解答”后，依次查看作答提纲、规范解题过程、条件与易错、本题知识点和知识串联，最后自评。原有动作标题及论述层次保留，步骤内部按句分行；原解答逐字符保留，公式顺序不变。知识点逐题整理，并用本题原解答摘录说明用法；直接相关时可进入对应知识卡回忆。整个专题回查仍独立保留。

单张原图限8MB，支持JPEG、PNG、WebP；保存时压缩为最长边1600像素的JPEG，每题最多3张，全部照片合计100MB。完整JSON备份包含照片，导入前显示张数，确认后按照片编号合并，重复导入不重复保存。照片存储不可用时，可明确选择“仅导出学习进度（不含照片）”；该文件名和内容均标明不含照片。服务器模式以数据库为准；页面中的“服务器已保存”表示已收到保存确认，断网时明确提示未保存并保留本机应急进度。照片上传失败须重新选择图片。


## 持续构建与镜像

`main`日常提交通过内容、服务、桌面与手机测试后发布`ghcr.io/paimoncai/study-econ:dev`。推送与package.json一致的版本标签（例如`v1.9.0`）发布版本镜像和部署包，正式版本同时更新`latest`。amd64与arm64各自原生构建并启动验证，通过后再组合镜像。

默认`compose.yaml`拉取预构建镜像；源码构建叠加`compose.build.yaml`。详细部署、更新与回退方法见DEPLOY.md。

## 学习分区

- 今日安排：保留每日三科各10道整题；另有每科最多10张背诵卡，优先到期再加入未背卡，分别计数。
- 刷题训练：题库、专题、随机练习与完整作答；题后可回查本专题知识卡，返回时保留原草稿与自评。
- 公式与背诵：微观75张、宏观64张、政经184张，支持科目/类型/章节/状态筛选、搜索、闭卷回忆草稿、展开核对与自评。
- 复盘与记录：集中查看三科错题、待复习知识卡、收藏与作答记录。
- 资料库：配套PDF/Excel，供查阅、打印与离线使用。

卡片正文摘自已交付手册，保留适用条件、边界和来源说明；包含119张公式与计算卡、6张起笔条件卡、198张概念与论述卡。专题关联由编者整理，不表示每题与卡片逐式对应。

背诵自评规则：不会当天再看，不熟次日，会背3天后。只保存每卡最近自评，修改不会重复增加已背张数。刷题与背诵不会相互补记完成，网站不自动判定回忆正确。

完整备份同时包含刷题进度、作答照片、背诵进度、历史文字草稿和回忆草稿。导入保留较新的背诵自评，旧备份不会清除当前背诵进度或照片。

`content/recall.json`是卡片快照。在完整本地资料库中，可执行`npm run import:handbooks`重新导入手册，再执行构建与检查；独立部署不要求服务器保存原手册。完整功能设计见FEATURE_PLAN.md。


## 连续操作与反馈

照片阅读器支持同题上下张、方向键切换和原尺寸/适应屏幕查看，关闭后回到原操作位置。删除先显示本题照片预览，默认聚焦取消；处理失败保留确认框供重试。

导入与迁移显示文件检查、照片检查、分批上传和提交结果，确认后的处理期间防止重复提交。完整备份下载交由浏览器下载列表管理，不提前宣称已完成下载。结束刷题组会提示未自评数量，确认结束后清理当前练习组，保留照片、记录和草稿。

键盘操作在筛选、收藏、自评和翻题后保留合适焦点，手机当前题号自动定位到可见范围。保存状态使用文字和颜色区分，控件不会因每次保存而被重复重建。请求超时明确提示，网络恢复可重试未同步修改；本机恢复副本不可写时，重新登录前先提示另存进度。

登录支持显示/隐藏口令、验证中状态、错误字段关联和过期表单恢复。练习室初始读取失败时提供重试入口，保留服务器已存数据。

消费者选择补全降价前后及补偿预算的相切无差异曲线，关键点配双轴投影和精确数值。互补、跨期、交换和投入图保留折点、角点、双原点和边界；福利题按实际面积绘制。宏观增加完整的IS–LM、AD–AS、动态AD–AS、索洛与AK、预期通胀和债务动态图；不同政策或冲击需要分别比较时分图说明，不把多种实验误接成同一路径。

每幅图可展开“教材依据与核查要点”，列教材或配套详解的名称、章节、PDF物理页及核查关系。图形按本题参数重新绘制，教材用于核对模型机制，不表示与教材示例同题同数；编者推导、示意参数和机制外推在图旁限定，教材扫描页不随部署包复制。详细记录见[252图逐图完善核查表](docs/diagram-teaching-review-20261031.csv)、[300题配图筛选表](docs/diagram-question-coverage-20261031.csv)和[本轮说明](docs/diagram-teaching-20261031.md)。

MI075原解答误将直接消费项下降当作含外部收益的总效用下降；固定y子问题中A总效用不变、B提高，属于帕累托改进。MA025原句未正确解释利率与利差的合计变化；总借款成本仍下降，利差上升仅削弱宽松。两处均在展开解答时先显示核查更正，保留原句供对照，不修改原题快照。

作答阶段先提示自行画图；展开解答后，图形按三个阶段展示初始条件、变化或构造、结论与检查点。每幅图单列坐标或关系、适用条件和原题解答依据。切换图形阶段不记录自评，不改变学习进度；字号或收藏重绘后在当前页面会话保留图形阶段。刷新后重新从初始阶段查看，不把查看阶段写入学习数据库。

手机可在图形区域左右滑动阅读，也可点“放大图形”查看当前阶段、图例和解释，关闭后焦点回到原按钮。密集轴值使用引线连接真实坐标，同值符号合并，不以改动经济坐标解决排版。图内箭头显示短名称或编号，图下始终提供完整含义；流程连线绕开节点。每图提供轴单位、关键点全称和方向的文字说明，打印显示最终完整图。图片均为本地SVG，无远程绘图服务和额外运行依赖。
