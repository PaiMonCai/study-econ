# 人大802练习室

三科各100道独立训练题，30个专题，50天每日每科10题。支持专题、随机练习、草稿自动保存、计时、作答提纲、完整解答、自评、错题、收藏、练习记录及JSON备份迁移。

计算题与论述题需要自行对照解答评估，网站不自动判分。练习数据仅存于当前浏览器，不自动跨设备同步，也不回写原Excel。

## 本机使用

在本目录运行 `npm start`，打开终端显示的网址。也可以直接打开 `dist/index.html`；为获得稳定的浏览器存储，建议使用本地网址。全部公式、字体和资料已放在本地，无需连接外部公式服务。

## 更新题库

`content/` 保存已交付题库和计划的快照；原编制目录及原手册不会被网站修改。编辑快照后运行 `npm install`、`npm run build`、`npm run check`。构建会预先转换全部公式，遇到解析错误时停止；`build-manifest.json`记录输入哈希和数量。

`dist/materials/` 是随站点提供的基础册、训练册和计划。原真题PDF不随站点上传；每题列出其原文件名、年份题号与PDF物理页。若本地原资料存在，重建时会同步这些配套手册。

## 学习数据

在“设置与备份”导出JSON；在另一设备或浏览器导入。导入合并练习记录和收藏，同一记录按最近修改时间保留，不重复计数。同题草稿以导入文件为准。更换域名会改变浏览器存储位置，应先导出再迁移。

站点默认私人访问。站点身份和静态目录在 `.openai/hosting.json`，不包含访问令牌。`node_modules/`、本机测试截图与临时日志不进入源仓库。
